Frequently Asked Questions

Is Metro Sathi official?

No. Metro Sathi is an unofficial, independent guide built by transit enthusiasts to improve commuting in Bengaluru.

Does the GPS require internet?

The GPS uses your device's local location hardware. While offline, the proximity tracker continues to run and falls back to a time-based simulator when you enter tunnels.

How can I report wrong platforms?

If you notice an incorrect platform number or terminal station label, please drop us a message using the form or create a Pull Request on GitHub.
